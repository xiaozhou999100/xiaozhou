# Prompt 记录目录（AI 工具提示词追溯）

> 课程设计：数字孪生车间智能监控与运维平台
> 本目录按阶段归档与 AI 工具的全部交互记录，满足课程「AI 使用披露 / 过程留痕」考核要求。

## 归档规范

1. **命名**：`stage<阶段序号>_<阶段名称>_<日期>.json`，例如 `stage1_data_preparation_2026-08-30.json`；
2. **内容**：记录每轮交互的「用户提示词原文 + AI 产出要点 + 验收结果」，与学习笔记中
   「prompt 原文 / AI 生成结果 / 最终验收效果」三段式留痕要求一致；
3. **同步更新**：每个开发阶段完成后立即归档，上下文压缩前先备份本目录再继续；
4. **关联证据**：Git 提交记录（`git log`）、`data/`、代码目录与本文档共同构成完整过程证据链。
